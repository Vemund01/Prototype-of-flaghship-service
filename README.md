# Public Funding Navigator: prototype

Prototype built for the BI course *AI for Business* (Autumn 2026). It helps Norwegian early-stage founders find relevant public funding schemes.

**Live page:** enable GitHub Pages (Settings → Pages → Deploy from branch → `main` / root) and open `https://<your-username>.github.io/<repo-name>/`.

Note: the AI steps call Claude only when the page runs inside claude.ai. On GitHub Pages the page runs in manual mode: it shows the prompts so you can paste them into your own chat tool and paste the reply back.
