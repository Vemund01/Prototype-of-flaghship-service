Public Funding Navigator

A working prototype of the flagship service. A founder describes the start-up in plain language; a built-in text engine extracts the facts, explicit rules check eligibility against a table of funding opportunities, a scoring model drafts a ranked shortlist, and an advisor approves it before it is sent. Everything runs in your browser: no AI service and no login needed.

Use fictional founder descriptions only. The built-in database is a snapshot from 2026-10-16 that the group has not yet verified, so no output here is advice.

Funding database

The shortlist is built only from this table: 27 Norwegian and European public schemes with their rules. You can also upload your own Excel file with the same columns. The rule check only works on the "Rule:" columns, so a file without them will let every scheme pass (use "Download the current database as Excel" to get a file with all columns). The file is read in your browser and is not sent anywhere.

Rule check

        
Explicit rules compare the confirmed facts with each scheme's documented conditions. The text engine takes no part in this step. "Needs checking" means a fact is missing or a condition needs human judgement.

        

        

        

        
Schemes with "Include in ranking" set to no (for example thin or supporting schemes) are shown here but are not ranked. Yellow means the start-up meets the conditions but the scheme's maximum is less than the amount sought; these are listed separately in the shortlist. EUR amounts are converted at an approximate rate set in the code (1 EUR = NOK 11.5). Calls whose last known deadline has passed are marked for the advisor.

        

        

      


      

        
Draft shortlist

        
The scoring model ranked only schemes that passed or partly passed the rule check and wrote the reasons from templates. Amounts, deadlines, dates checked and links are filled in from the database.

Limits
          
    
            
  • The rules come from the 'Rule:' columns of the database file. The built-in rules have not yet been verified against the official pages.
    • 
            
  • Judgement-based criteria (for example "simple, easily copied solutions") are flagged for the advisor, not decided by rules.
    • 
            
  • The extraction and ranking are rule-based, so the same description always gives the same result. Unusual wording can be missed: always check the facts in step 2.
    • 
            
  • Amounts in EUR are converted at an approximate fixed rate (1 EUR = NOK 11.5), and deadlines are compared with today's date using the last known deadline in the database.
    • 
            
  • Several EU schemes depend on the sector and on women leadership; these are detected from keywords and should be checked in step 2.
    • 
            
  • The advisor is simulated by whoever uses this page. Run logs stay in this browser session until downloaded.
